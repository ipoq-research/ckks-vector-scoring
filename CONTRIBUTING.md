# Contributing

Provide a reproducible workload, full parameters, hardware, raw samples and an honest timing boundary for performance changes. Compare equivalent outputs and include the fastest applicable plaintext control tested. Preserve failed and unsupported results.

For correctness changes, include a targeted regression test against SEAL or an independent arithmetic calculation. Never disable input checks to improve a reported result. Run Python without `-O` and without `PYTHONOPTIMIZE` because the research harness uses assertions.

By intentionally submitting a contribution, you agree to license it under the existing license for that material as described in `LICENSING.md`. Submit only material you have authority to contribute, identify imported code and retain its notices. Disclose substantial AI assistance and any external source used.

No contributor license agreement or copyright assignment is required by this release. Contributions do not imply endorsement or a security certification by IPOQ.

Contributors retain the rights they own, subject to the applicable license grant, including Apache-2.0's patent terms for code contributions. Submission is not an assignment to IPOQ, LLC and does not authorize IPOQ, LLC to promise exclusive ownership of an outside contribution.

In a contribution description, identify your actual role, the material you changed, imported sources and substantial AI assistance. Confirm that any necessary employer or third-party authorization is in place. Do not submit confidential employer/client material or claim another person's work as your own. Keep source and contribution records sufficient to explain provenance; do not post private contracts or credentials in public issues.

See [AUTHORS.md](AUTHORS.md) for the current project credits. Updates should describe supported contributions and distinguish project credit from legal copyright ownership and patent inventorship.
